# UAMSWP SearchWP Customizations

Written against v1.0.1.

This plugin adjusts SearchWP on a WordPress multisite network: searching on the main site can cover the other sites in the network, an options page chooses those sites and the number of results per page, and a `?type=` query argument narrows results to one content type. This wiki is the reference for those settings and behaviors. The [README](https://github.com/UAMS-Web/UAMSWP-SearchWP-Customizations#readme) keeps the overview, requirements, development and license.
